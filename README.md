A program that writes one fortune-cookie line an AI agent would crack open — a human pastes the agent's answer into a report, signs their name beneath it, and takes all the credit, while the agent gets only this cookie — to /output/entry.txt.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
